# DS Defense — Projects, Sources, and Contributors

This document tracks projects, repositories, publications, tools, and contributors that may be relevant to DS Defense.

Its purpose is to document provenance and help original authors and maintainers find and update their work.

## Important

Being listed here does **not** imply:

- endorsement of DS Defense;
- transfer of ownership;
- permission to redistribute source code;
- agreement to participate;
- adoption of a common license.

Where redistribution rights are unclear, this repository should link to the original source rather than copy its contents.

## Status labels

Use the following labels where helpful:

**Confirmed**  
Information has been confirmed by an original author or maintainer.

**Public source**  
Information is based on publicly available project information but has not yet been confirmed by the maintainer.

**Contacted**  
An attempt has been made to contact the relevant author or maintainer.

**License unclear**  
The applicable redistribution license has not yet been confirmed.

**Looking for maintainer**  
The project appears relevant, but we have not yet identified an active maintainer.

# GitHub Discussion template

## Call for Contributors: Help Build DS Defense

DS Defense is now open for community coordination and contributions.

This repository was created to bring together projects, implementations, research, tools, and contributors working on related topics.

A very important point:

**I am acting primarily as the initial coordinator of this repository. I am not claiming authorship of work created by other contributors.**

Many relevant projects appear to have been developed independently and are currently distributed across different repositories.

The goal of DS Defense is to make that work easier to discover, connect the people behind it, and create a shared space where original authors can decide how their work should be represented.

## We are looking for

We would especially like to hear from:

- original authors;
- current maintainers;
- past contributors;
- researchers;
- people who know the history of relevant projects;
- people who can identify missing repositories or contributors.

## If you recognize your work

Please reply to this Discussion or open a Pull Request.

You can simply write:

```text
Project:
My GitHub username:
My role:
Author / Maintainer / Contributor / Other

Authoritative repository:
License:

I would like to:
[ ] Maintain this project entry
[ ] Contribute code
[ ] Contribute documentation
[ ] Correct attribution
[ ] Keep the project externally hosted and linked here
[ ] Discuss first
```

You do not need to move your project into this repository.

Linking to your existing repository is completely acceptable.

## Current priorities

Right now we are primarily trying to:

1. identify the correct original projects;
2. identify original authors and maintainers;
3. confirm attribution;
4. confirm licensing;
5. understand which contributors would like to participate;
6. determine the appropriate long-term repository structure.

If you know someone who should be part of this conversation, please feel free to mention them.

Thank you to everyone whose previous work makes this project possible.
